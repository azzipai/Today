# Today

一款「每日计划 + 记账」的个人网页应用。以天为周期，帮你管好今天要做什么、钱花到哪里，并提供每周完成率、支出统计和到期提醒。

纯前端实现，数据保存在浏览器本地（localStorage），无需后端、无需账号，部署即可用。

## 功能

- **每日计划**：当天任务当天看，支持子步骤勾选与分点记录「完成了什么 / 学到了什么」
- **Inbox**：随手记录想法与想做的小事，跨天延续
- **Deadline**：带截止日期和时间的中期任务，状态自动变色提醒
- **记账**：按分类记录每笔消费，常用分类一键点选，支持分类管理与删除撤销
- **统计**：每周完成率热力图、本周支出、每日支出、分类占比
- **提醒**：截止前 12 小时提醒、每晚 23:00 完成进度 + 花销总结
- **报告导出**：导出周报 / 月报（HTML，可打印为 PDF）
- **数据备份**：导出 / 导入 JSON

## 技术栈

- Vite + React
- 原生 CSS（无 UI 组件库）
- localStorage 数据存储（无后端）
- PWA（可添加到主屏幕、离线缓存）

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 构建与部署

```bash
npm run build
```

产物在 `dist/` 目录，可拖拽到 Netlify Drop 部署；仓库已含 `netlify.toml`，关联 GitHub 后会自动构建部署。

## 数据说明

数据保存在浏览器 localStorage 中，不会上传到任何服务器。清除浏览器数据或更换浏览器会导致数据丢失，请定期在「设置」中导出备份。
